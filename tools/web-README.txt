rdir-web —— R-Dir 无窗口 web 服务
==================================

【这是什么】
不装任何运行时（无 WebView2 依赖）、无桌面的 Windows 机器也能跑的
R-Dir 文件服务：启动后用浏览器（本机或局域网另一台电脑/手机）访问，
即获得完整的文件管理界面——浏览、上传、下载、复制移动删除、压缩解压、
SFTP 远程、目录/文本比对、搜索等。

【快速开始】
1. 双击 rdir-web.exe（或命令行启动，见下方选项）；
2. 终端会打印一行带令牌的访问链接（http://127.0.0.1:8420/login?k=…），
   用浏览器打开它即可进入；令牌换成本地 cookie，30 天有效；
3. 局域网其他设备访问：加参数 --listen 0.0.0.0:8420 重启，
   并用本机局域网 IP 组装同样的 /login?k= 链接。

【命令行选项】
  --listen HOST:PORT   监听地址（默认 127.0.0.1:8420；0.0.0.0 开放局域网）
  --token TOKEN        访问令牌（默认随机 32 位 hex，每次启动重新生成）
  --data-dir DIR       数据目录（默认便携标记 > 用户配置目录）
  --read-only          只读模式：浏览/预览/下载可用，写操作（含上传）全拒绝
  -h, --help           显示帮助

【数据与配置】
- 与桌面版 R-Dir 共用同一份配置（会话/收藏/主题/SFTP 服务器清单/插件开关），
  可与桌面版同时运行；
- 桌面版关掉的插件（设置 → 插件）在 web 端同步关闭。

【安全须知】
- 默认只监听 127.0.0.1，仅本机可访问；--listen 0.0.0.0 开放局域网属显式选择；
- 无内置 TLS：暴露公网请务必套反向代理（Nginx/Caddy）并启用 HTTPS；
- 双击打开的文件在新标签页展示，已做沙箱隔离（打开的文档无法访问服务）；
- 只读分享场景请使用 --read-only。

【系统要求】
- Windows 10 / 11（x64）。web 服务不依赖 WebView2，无桌面环境也可运行
  （如 Windows Server 的计划任务/服务化部署）。
