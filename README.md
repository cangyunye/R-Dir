# Rust File Manager

基于 **Tauri 2 + Rust + React + TypeScript + Tailwind v4 + shadcn/ui** 的跨平台文件管理器（macOS / Windows）。

> 🚀 最新发布见 [Releases](https://github.com/cangyunye/R-Dir/releases)（GitHub Actions 自动打包 Win + Mac）。

### macOS 安装说明

应用未使用 Apple 开发者证书签名（个人项目），首次打开若提示「已损坏，无法打开」，执行：

```bash
xattr -cr /Applications/R-Dir.app
```

或右键应用 →「打开」→ 确认即可正常使用。

## v0.1.0 功能速览

- **资源管理器式布局**：菜单栏 / 标签页（可拖拽排序）/ 地址栏（输入补全）/ 左侧快速访问 + 磁盘导航
- **详情列表**：lsd 风格字段（名称 / 大小 / 修改时间 / 类型 / 权限）、扩展名图标、列头排序、隐藏文件开关
- **完整文件操作**：复制 / 剪切 / 粘贴（跨窗格跨标签）/ 重命名 / 删除（回收站）/ 新建文件夹与文本文件 / 复制路径 / 撤销重做
- **多选与框选**：Shift 范围、⌘·Ctrl 追加、矩形框选、全选/反选
- **分屏**：VSCode 式左右 / 上下 / 四宫格，分割条拖拽，窗格独立导航；**跨窗格拖拽**（默认复制，Option/Alt 移动）
- **搜索**：文件名（默认当前层 / fd 引擎递归检索）+ 内容搜索（VSCode 风格，默认当前层，高亮定位）
- **快捷键系统**：统一动作注册表，菜单同步显示当前平台键位，⌘,/F1 查看一览
- **主题**：深色 / 浅色一键切换（右上角日 / 月）

📖 使用教程见 [docs/user-guide.md](docs/user-guide.md)。

## 已实现

### M0 可用浏览器
- 菜单栏（文件 / 编辑 / 查看 / 转到 / 窗格 / 帮助）
- 多标签页（每标签独立 pane 树、历史、排序、选中状态）
- 工具栏：后退 / 前进 / 上级 / 刷新 + 地址栏（输入路径回车跳转）
- **地址栏目录补全**：输入前缀实时提示匹配目录（支持 `~`、相对路径），↑↓ 选择、Tab 补全、Enter 直达
- 左侧导航：快速访问（主目录、桌面、文档、下载、图片、音乐、影片）+ 磁盘/卷枚举（macOS `/Volumes`、Windows 盘符，编译时切换，已去重根卷符号链接）
- 详情列表：lsd 风格默认字段（名称 / 大小 / 修改时间 / 类型 / 权限），扩展名图标映射，列头排序，显示隐藏文件开关
- 右侧搜索面板：文件名搜索（默认仅当前层，前端本地过滤）；内容搜索占位（计划基于 ripgrep）
- 底部：状态栏（条目数、选中信息、操作提示）+ 属性栏（选中文件详细属性）
- 深色/浅色主题（shadcn CSS 变量，`dark` class 切换）

### M1 文件操作
- 复制 / 剪切 / 粘贴（应用内剪贴板，跨 pane、跨标签共享）
- 重命名（行内编辑，Enter 确认 / Esc 取消）
- 删除（进回收站，`trash` crate）
- 新建文件夹 / 新建文件（创建后自动进入重命名）
- 右键菜单：打开 / 复制 / 剪切 / 重命名 / 删除（回收站）/ 复制路径 / 刷新
- **多选**：Shift+点击范围选择、⌘/Ctrl+点击追加、⌘/Ctrl+A 全选、点击空白取消、Esc 取消；对多选批量执行复制/剪切/删除/粘贴
- 快捷键：⌘/Ctrl+C / X / V / A / R / N / W、F2 重命名、Delete 删除、Backspace 上级、Esc 取消选择、⌘\ 左右分屏、⌘J 上下分屏
- 文件双击经系统默认应用打开（tauri-plugin-opener）

### M2 分屏（VSCode 式）
- 窗格树模型：`PaneNode = Pane | Split{dir, ratio, a, b}`
- 左右分屏 / 上下分屏 / 组合成四宫格，递归可无限分割
- 分割条可拖拽调整比例（0.1–0.9）
- 每个窗格独立：路径、历史、排序、选中状态、属性栏
- **跨窗格拖拽**：HTML5 DnD，从一个窗格拖文件到另一个窗格，默认**复制**，按住 Option/Alt 切换为**移动**；拖拽悬停显示"复制/移动到此处"，落入目标后自动刷新源与目标窗格
- 窗格菜单：关闭当前窗格、聚焦下一窗格（⌘K 循环）

### M3 内容搜索（VSCode 风格）
- Rust 端 `search.rs`：字面量关键词（`regex::escape`），后台线程池执行不阻塞 UI
- 默认仅搜索**当前层**直接子文件，可勾选"递归子目录"
- 自动跳过：隐藏文件/目录、二进制文件（前 8KB NUL 检测）、>4MB 文件、非 UTF-8
- 每文件最多 50 条、总计 300 条命中，单行截断 300 字符
- 大小写开关（Aa）；结果行显示相对路径 + 行号 + 关键词高亮
- 点击结果：跳转到文件所在目录并自动选中该文件

### M4 快速文件检索（fd 引擎）
- `find.rs` 基于 `ignore` crate 实现（fd 官方使用的底层遍历引擎，行为对齐 fd 语义；fd-find 10.x 已移除库模式，故直接采用其引擎）
- **正则匹配文件名** + **智能大小写**（模式含大写自动区分大小写）
- 递归遍历、尊重 `.gitignore` / `.ignore`、默认跳过隐藏项、结果按路径排序
- 搜索结果上限 500，后台线程池执行
- 前端：搜索面板"文件名" tab 勾选 **"递归检索（fd 引擎）"** 即启用
- 点击目录直接进入；点击文件跳转到所在目录并选中

### M5 快捷键系统（P1 统一分发 + 撤销/重做）
- **动作注册表** `src/lib/keymap.ts`：actionId 唯一标识全部动作，键位只是默认绑定（为配置化铺路）
- 统一逻辑键 `mod` = macOS ⌘ / Windows Ctrl；macOS 标签切换保留 `Ctrl+Tab`（系统占用 ⌘+Tab）
- 三层上下文：输入框聚焦整体放行（⌘V 粘贴文本等原生行为不被劫持）、窗格层、全局层
- 默认映射覆盖：导航（上级/后退/前进/刷新/地址栏/主目录）、选择（全选/反向/取消）、文件操作（复制/剪切/粘贴/复制到当前目录/重命名/打开/删除/永久删除/新建文件夹/新建文件/复制路径/撤销/重做/属性栏）、标签页（新开/关闭/循环切换/跳转 1-9/恢复关闭）、分屏（左右/上下/下一窗格/关窗格/重置比例）、搜索（文件名/内容）、视图全局（隐藏文件/主题/设置/F1）
- **撤销/重做栈**：复制（撤销=删除产物）、移动（撤销=按原目录移回）、重命名、新建（撤销=删除）；删除进回收站不进栈
  - Rust `copy_entries` 返回实际创建路径、`move_entries` 返回 (源, 目标) 路径对支撑撤销
  - 新增 `permanent_delete_entries`（绕过回收站，需确认，不可撤销）
- 设置对话框（⌘,/Ctrl+, 或 F1）：快捷键一览（分组展示当前平台键位），P2 将加入录制与持久化

## 运行

```bash
npm install
npm run tauri dev      # 开发模式（热更新）
npm run tauri build    # 打包
```

## 目录结构

```
src/                    # 前端（React + TS）
├── App.tsx             # 主布局与全局状态（标签/pane 树/剪贴板/快捷键）
├── components/         # 菜单栏、标签栏、工具栏(地址补全)、侧栏、分屏、文件列表、搜索、状态栏
└── lib/                # Tauri API 封装、类型、pane 树工具、格式化
src-tauri/              # Rust 后端
└── src/
    ├── lib.rs          # 命令注册（list_dir / complete_path / 文件操作 / 磁盘 / 路径）
    ├── fs_ops.rs       # 目录扫描、条目元数据、路径补全
    ├── ops.rs          # 复制/移动/重命名/删除(回收站)/新建
    └── volumes.rs      # 磁盘/卷与快速访问路径
```

## 路线图

- **M6 打磨**：配置持久化（快捷键录制 UI / 默认字段 / 视图偏好）、大目录虚拟滚动、系统级剪贴板与拖拽
- **M7+ 扩展体系**
  - 快捷键配置：用户可自定义键位映射（配置文件驱动，冲突检测）
  - 可扩展访问协议插件：路径栏输入协议头解析
    - `sftp://`：通过 SSH/SFTP 访问远程目录
    - `http(s)://`：解析 nginx `autoindex on` 生成的 index 页面，把文件链接和上下层 URL 解析成"文件/文件夹"浏览（只读）
  - 打开方式注册表：扩展名 → 外部播放器/看图器；文本预览（前 2000 字）
