# Rust File Manager 用户指南

> 面向 Windows 与 macOS 的现代文件管理器：参考 Windows 资源管理器的界面，分屏与搜索参考 VSCode，底层基于 Tauri 2 + Rust。

## 安装与启动

### 开发模式（从源码运行）

需要：Node.js 22+、Rust（stable）、各平台系统依赖（macOS 需要 Xcode Command Line Tools；Windows 需要 WebView2，一般随系统自带）。

```bash
npm install
npm run tauri dev
```

### 打包安装

```bash
npm run tauri build   # 产物在 src-tauri/target/release/bundle/
```

正式发布版本请在 [GitHub Releases](https://github.com/cangyunye/R-Dir/releases) 下载对应平台安装包：
- **macOS**：`.dmg` 或 `.app.tar.gz`（Apple Silicon / Intel 分别提供）
- **Windows**：`.msi` 或 NSIS `.exe` 安装器

## 界面布局

```
┌ 菜单栏 ──────────────────────────────── ☀/☾ ┐
├ 标签页 [ Tab1 ] [ Tab2 ] [ + ]            │
├ 后退 前进 上级 刷新  [ 地址栏 …]        ⌕ │
├ 左侧导航 │ 文件列表（详情视图）          │ 搜索面板 │
│ 快速访问 │ 名称 大小 修改时间 类型 权限   │          │
│ 磁盘/卷  │ …                             │          │
├ 属性栏（选中项详情）                       │
├ 状态栏：路径 · N 项 · 已选 M 项 · 大小    │
└──────────────────────────────────────────┘
```

- **菜单栏**：文件 / 编辑 / 查看 / 转到 / 窗格 / 帮助；右上角日/月图标切换深色浅色主题。
- **标签页**：可拖动调整顺序；每个标签拥有独立的窗格树、历史与选中状态。
- **左侧导航**：快速访问（主目录、桌面、文档、下载等）+ 磁盘/卷列表（macOS `/Volumes`、Windows 盘符）。
- **地址栏**：输入路径回车跳转；输入时自动补全目录（支持 `~` 与相对路径）；`Tab` 循环候选。
- **搜索面板**：右侧，含"文件名"与"内容"两个标签页（见下文搜索）。
- **底部**：属性栏显示选中文件详情；状态栏显示路径、条目数与选中统计。

## 导航

| 操作 | Windows | macOS |
|---|---|---|
| 上一级目录 | `Alt+↑` / `Backspace` | `⌘+↑` |
| 后退 / 前进 | `Alt+←` / `Alt+→` | `⌘+[` / `⌘+]` |
| 刷新 | `F5` | `⌘+R` |
| 聚焦地址栏 | `Ctrl+L` | `⌘+L` |
| 前往主目录 | `Ctrl+Shift+H` | `⌘+Shift+H` |

在地址栏输入 `~`、`.`、`..`、相对路径均可解析。

## 文件操作

| 操作 | Windows | macOS |
|---|---|---|
| 复制 / 剪切 / 粘贴 | `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | `⌘+C` / `⌘+X` / `⌘+V` |
| 复制到当前目录 | `Ctrl+D` | `⌘+D` |
| 重命名 | `F2` | `F2` |
| 打开 | `Enter` / 双击 | `Enter` / 双击 |
| 删除（回收站） | `Delete` | `⌘+Delete` |
| 永久删除（需确认） | `Shift+Delete` | `⌘+Option+Delete` |
| 新建文件夹 / 文件 | `Ctrl+Shift+N` / `Ctrl+Alt+N` | `⌘+Shift+N` / `⌘+Option+N` |
| 复制完整路径 | `Ctrl+Shift+C` | `⌘+Shift+C` |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y` | `⌘+Z` / `⌘+Shift+Z` |

- 粘贴支持跨窗格、跨标签；复制/移动/重命名/新建均可撤销（删除到回收站不进撤销栈）。
- 右键文件行：打开 / 复制 / 剪切 / 重命名 / 删除 / 复制路径 / 刷新。
- **右键列表空白处**：新建文件夹 / 新建文本文件 / 粘贴 / 全选 / 反向选择 / 刷新。

### 多选与矩形框选

- `Shift`+点击：连续范围选择；`Ctrl/⌘`+点击：逐项追加/取消。
- `Ctrl/⌘+A` 全选、`Ctrl/⌘+Shift+A` 反向选择、`Esc` 取消选择。
- **按住左键拖动**（从未选中行或空白处开始）出现半透明矩形框，松开批量选中；按住 `Shift/Ctrl/⌘` 拖动为追加模式。
- 从**已选中项**上按下拖动 = 拖拽文件（见下文）。

### 跨窗格拖拽

1. 打开分屏（`Ctrl+\`/`⌘+\` 左右，`Ctrl+J`/`⌘+J` 上下）。
2. 从已选中文件上按住拖动到另一窗格，顶部出现"复制到此处"提示。
3. 默认**复制**；按住 `Option`/`Alt` 切换为**移动**。松开即落盘，源与目标窗格自动刷新。

## 分屏

- `Ctrl+\` / `⌘+\`：左右分屏；`Ctrl+J` / `⌘+J`：上下分屏；可反复分割成四宫格甚至更多。
- 拖动窗格间分割条调整比例（0.1–0.9），`Ctrl+0`/`⌘+0` 一键重置为均分。
- `Ctrl+Shift+\` / `⌘+Shift+\`：聚焦下一窗格；`Ctrl+Shift+W` / `⌘+Shift+W`：关闭当前窗格。
- 每个窗格独立导航、历史、排序与选中状态，属性栏显示当前窗格选中项。

## 搜索

面板在工具栏右侧（`Ctrl+F`/`⌘+F` 打开并聚焦"文件名"；`Ctrl+Shift+F`/`⌘+Shift+F` 切到"内容"）。

**文件名 tab**
- 默认仅搜索当前层，实时过滤文件名。
- 勾选 **"递归检索（fd 引擎）"** 后：递归遍历整个目录树，支持正则（如 `^src/`）与智能大小写，尊重 `.gitignore`；点击目录直接进入、点击文件跳转并选中。

**内容 tab**
- 默认仅搜索当前层文件内容，可勾选"递归子目录"与"区分大小写"。
- 自动跳过二进制、超大（>4MB）、非 UTF-8 与隐藏文件；结果显示路径 + 行号 + 高亮，点击跳转定位。

## 标签页

- `Ctrl+T` / `⌘+T` 新建；`Ctrl+W` / `⌘+W` 关闭；`Ctrl+Shift+T` / `⌘+Shift+T` 恢复刚关闭的标签。
- `Ctrl+Tab` / `Ctrl+Shift+Tab` 循环切换；`Ctrl+1..9` / `⌘+1..9` 直接跳转。
- 鼠标按住标签左右拖动可调整顺序。

## 主题

- 右上角 ☀/☾ 按钮切换深色/浅色主题；也可用 `Ctrl+Alt+T` / `⌘+Option+T`。

## 快捷键一览

菜单栏"帮助 → 快捷键一览"，或按 `Ctrl+,` / `⌘+,` / `F1`，可查看全部动作在当前平台的键位。

## 常见问题

- **macOS 打开提示"已损坏"**：从非 App Store 下载的应用需在"系统设置 → 隐私与安全性"中允许，或右键应用 → 打开。
- **拖拽文件后目标窗格没变化**：确认松开时鼠标在目标窗格内部（提示条出现的位置）；拖到分割条上不会落盘。
- **内容搜索无结果**：默认仅当前层且跳过隐藏/二进制文件；大目录请勾选"递归子目录"。
- **地址栏补全无效**：输入路径前缀后等待约 0.1 秒出现下拉；`Tab` 仅补全不跳转，`Enter` 才跳转。
