# Rust File Manager 用户指南

> 面向 Windows 与 macOS 的现代文件管理器：参考 Windows 资源管理器的界面，分屏与搜索参考 VSCode，底层基于 Tauri 2 + Rust。
> 本指南覆盖到 v0.31.1；逐版本变更见 [CHANGELOG.md](../CHANGELOG.md)。

## 安装与启动

### 开发模式（从源码运行）

需要：Node.js 22+、pnpm、Rust（stable）、各平台系统依赖（macOS 需要 Xcode Command Line Tools；Windows 需要 WebView2，一般随系统自带）。

```bash
pnpm install
pnpm tauri dev
```

### 打包安装

```bash
pnpm tauri build   # 产物在 src-tauri/target/release/bundle/
```

正式发布版本请在 [GitHub Releases](https://github.com/cangyunye/R-Dir/releases) 下载对应平台安装包：
- **macOS**：`.dmg` 或 `.app.tar.gz`（Apple Silicon / Intel 分别提供）
- **Windows**：NSIS `-setup.exe` 安装器（只发布 NSIS，不发布 `.msi`；从旧版 MSI 升级需先手动卸载一次旧版，见 README）

首次打开若提示「已损坏，无法打开」（应用未做公证签名）：执行 `xattr -cr /Applications/R-Dir.app`，或右键应用 →「打开」→ 确认。

## 界面布局

```
┌ 标签栏（兼标题栏）[ Tab1 ] [ Tab2 ] [ + ]      ⚙ 🌙 ⋮ │─ □ ×┐
├ 后退 前进 上级 刷新  [ 地址栏 …]        ⌕ │
├ 左侧导航 │ 窗格头路径条                    │ 搜索(模态) │
│ 快速访问 │ 文件列表（详情/大图标）          │            │
│ 磁盘/卷  │ 名称 大小 修改时间 类型 权限     │            │
│ 彩色标签 │                                  │  预览栏(拉门)│
│ 远程服务器│                                 │            │
├ 属性栏（选中项详情）                       │
├ 状态栏：路径 · N 项 · 已选 M 项 · 传输 · 分享│
└──────────────────────────────────────────┘
```

- **无边框标题栏**：窗口无系统边框，标签栏兼任标题栏——空白处按住拖动即可移动窗口，双击空白最大化/还原；右上角为自绘「最小化 / 最大化 / 关闭」按钮，所有退出路径（含 ⌘Q、菜单退出）统一弹「保存会话布局？」询问。
- **右上角常驻区**：设置（齿轮）、深浅色主题切换、⋮ 应用菜单（命令面板 `Ctrl/⌘+K` 与全部功能入口）。
- **标签页**：OneNote 式彩色色块（按标签稳定取色，深色实色块 / 浅色洗色），可拖动排序、双击重命名、中键关闭；每个标签拥有独立的窗格树、历史与选中状态。
- **窗格头路径条**：每个窗格顶部有独立面包屑——点任意段在该窗格内导航并激活该窗格，多窗格时右侧有关闭钮；**按住路径条拖到另一窗格可直接互换两窗格位置**（v0.30）。
- **地址栏（面包屑路径栏）**：默认按「浅色彩虹箭头」分段展示当前路径——**点分段直接跳到该层**（末段为单选文件时点击回到其所在目录）；路径过长自动横向滚动到末段。**点空白处 / 铅笔图标 / `Ctrl/⌘+L`** 切换到编辑模式：显示完整路径文本，可自由复制与输入（回车跳转、自动补全目录、支持 `~` 与相对路径、`Tab` 循环候选），`Esc` 或点击别处回到面包屑。路径栏右键可「编辑路径 / 复制路径 / 粘贴并转到 / 刷新 / 属性」。地址栏同时是迷你命令行（见「导航」）。
- **搜索**：居中模态框（v0.29 起），含「文件名」与「内容」两个标签页（见下文搜索）。
- **底部**：属性栏显示选中文件详情；状态栏显示路径、条目数与选中统计、传输进度（含停止按钮）、失败提示与「分享」入口。

## 导航

| 操作 | Windows | macOS |
|---|---|---|
| 上一级目录 | `Alt+↑` / `Backspace` | `⌘+↑` / `⌫` |
| 后退 / 前进 | `Alt+←` / `Alt+→` / 鼠标侧键 | `⌘+[` / `⌘+]` / 鼠标侧键 |
| 刷新 | `F5` | `⌘+R` |
| 聚焦地址栏 | `Ctrl+L` | `⌘+L` |
| 前往主目录 | `Ctrl+Shift+H` | `⌘+Shift+H` |

在地址栏输入 `~`、`.`、`..`、相对路径均可解析。

- **标签切换不重读目录**（v0.22.1）：切回已看过的标签/窗格时直接显示内存中的列表（瞬时切换）；**目录内容被外部修改时自动感知**（v0.26.1 起后台监视，约 2 秒内自动刷新，未激活的标签同样生效），也可随时按 `F5` / `⌘R` 或地址栏同路径回车强制重读。最近 8 个标签的界面状态（滚动、选中、排序）在切换间保留。
- **中键点击目录**：在新标签页打开该目录。
- **键盘快速定位（QuickJump）**：焦点在文件列表时直接键入字符，弹出 fzf 式模糊匹配浮层——对当前目录条目做子序列模糊匹配，匹配字符高亮、按相关度排序；↑↓ 或鼠标悬停移动高亮并**实时驱动背后列表滚动定位**，回车在文件上定位选中、在目录上直接进入，Esc 还原打开前的选中（含多选）。支持退格、粘贴与中文输入法。

### 地址栏执行命令（v0.22.0）

回车按「路径优先、命令兜底」解析：输入先按路径校验（带空格的合法路径不受影响）；不是路径且首词命中 PATH 中的可执行文件时，**新开终端窗口 cd 到当前窗格目录执行整条命令**（mac 在 Terminal、win 在 PowerShell 中执行；参数、管道原样交给 shell）。两者都不是时红字提示「路径不存在，也不是 PATH 中的命令」。SFTP / HTTP / 标签窗格中不启用命令兜底。

- 命令补全扫描范围 = 进程 PATH ∪（macOS）`/opt/homebrew/bin`、`~/.cargo/bin`、`~/.local/bin`、`~/bin` 等常见目录（从 Finder 启动的 GUI 应用拿到的 PATH 常缺家酿目录，已自动补齐）；同名命令按 PATH 顺序先到先得，结果缓存 10 分钟。
- macOS 首次执行需在「系统设置 → 隐私与安全性 → 自动化」中授权本应用控制"终端"。
- 可在 设置 → 插件 停用「地址栏命令」插件整体关闭该功能。

## 文件操作

| 操作 | Windows | macOS |
|---|---|---|
| 复制 / 剪切 / 粘贴 | `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | `⌘+C` / `⌘+X` / `⌘+V` |
| 复制到当前目录 | `Ctrl+D` | `⌘+D` |
| 重命名 | `F2` | `F2` |
| 打开 | `Enter` / 双击 | `Enter` / 双击 |
| 删除（回收站） | `Delete` | `⌘+⌫` / `fn+⌫` |
| 永久删除（需确认） | `Shift+Delete` | `⌘+Option+⌫` |
| 新建文件夹 / 文件 | `Ctrl+Shift+N` / `Ctrl+Alt+N` | `⌘+Shift+N` / `⌘+Option+N` |
| 复制完整路径 | `Ctrl+Shift+C` | `⌘+Shift+C` |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y` | `⌘+Z` / `⌘+Shift+Z` |

- **撤销 / 重做**：复制、移动、重命名、新建、删除（回收站）均可撤销/重做；右键与空白处菜单均有入口。永久删除不可撤销。
- **系统剪贴板互操作**：`⌘/Ctrl+C/X/V` 与系统剪贴板互通——应用内复制可在 Finder / 资源管理器直接粘贴，系统里复制的文件也可在应用内粘贴；Windows 上剪切语义双向保留（粘贴一次后失效，与资源管理器一致）。
- **删除确认**：所有删除统一弹应用内确认框（目录展示递归统计：文件数 · 文件夹数 · 字节），`Enter` 确认、`Esc` 取消；永久删除、SFTP 同名覆盖等确认同样为应用内弹窗。
- **同名冲突裁决**：覆盖 / 全部覆盖 / 改名（`name_1.ext`）/ 停止，目录递归合并、内部同名逐条提示。目录复制语义分级（v0.28）：复制目录到**别的目录**（如另一窗格）遇同名直接覆盖不再逐条询问；在**同一目录原位复制**（`Ctrl+D`）遇同名询问「是否新增目录」，确认后自动命名 `名字 (2)`。文件级冲突展示源/目标的大小与 MD5（v0.37）：逐条裁决时按当前条目查询，MD5 一致提示内容相同；「全部覆盖」不逐条查询，目录冲突不查询。
- **失败提示**（v0.31.1）：传输 / 覆盖失败在窗口中央红色浮层提示（停留 3.6 秒），状态栏同时留底；只读、被占用等会给出具体原因。粘贴进行中重复触发自动忽略。
- **新建后直接重命名**：新建文件夹 / 文本文件后自动进入行内重命名（键入即覆盖默认名，`Enter` 提交 / `Esc` 取消）；标签、HTTP 等虚拟视图不支持新建（会给出提示）。
- 右键文件行：打开 / 打开方式 / 终端 / Git 打开 / 常用工具条 / 分享（目录）/ 压缩为 / 复制 / 剪切 / 重命名 / 删除 / 复制路径 / 标签 / 添加到快速访问 / 属性。
- **右键列表空白处**：常用工具条 / 新建文件夹 / 新建文本文件 / 粘贴 / 终端 / 全选 / 反向选择 / 刷新 / 粘贴并转到 / 属性（当前目录）。

### 多选与矩形框选

- `Shift`+点击：连续范围选择；`Ctrl/⌘`+点击：逐项追加/取消。
- `Ctrl/⌘+A` 全选、`Ctrl/⌘+Shift+A` 反向选择、`Esc` 取消选择（预览启用后 `Space` 让位给预览开关，不再加选）。
- **按住左键拖动**（从未选中行或空白处开始）出现半透明矩形框，松开批量选中；按住 `Shift/Ctrl/⌘` 拖动为追加模式。
- 从**已选中项**上按下拖动 = 拖拽文件（见下文）。

### 跨窗格拖拽

1. 打开分屏（`Ctrl/⌘+\` 左右，`Ctrl/⌘+J` 上下）。
2. 从已选中文件上按住拖动到另一窗格，顶部出现"复制到此处"提示。
3. 默认**复制**；按住 `Option`/`Alt` 切换为**移动**。松开即落盘，源与目标窗格自动刷新。
4. **拖到目录行 / 文件夹图标上 = 进入该目录**（而不是窗格当前目录），同窗格、跨窗格都可以；悬停时该目录条目高亮，多选的文件一起进去。把文件夹拖到它自己身上不动作。
5. 跨后端直接可用：**本地 → SFTP 窗格松手即上传**（目标已有同名条目时先弹覆盖确认，单文件同名附源/目标大小对比，不显示 MD5——v0.37）；SFTP → 本地松手即下载。也可从应用拖出到系统（Finder / 资源管理器）或浏览器的上传区，详情列表与大图标视图均支持。
6. 本地 → SFTP 的复制/粘贴与拖拽上传一致：目标存在同名条目时先确认再覆盖。

### 属性

右键文件 / 文件夹 →「属性」：类型、大小、时间与权限；文件夹做**递归统计**（文件数 · 文件夹数 · 字节），数字老虎机式滚动。列表空白处右键「属性（当前目录）」可统计整个目录。

### 压缩

右键选中项 →「压缩为」：zip / tar / tgz 三种格式（调用系统命令，带进度条）；多选可一起打包，归档内为相对路径。

## 视图模式（v0.27）

每个窗格可独立切换视图（窗格头右侧切换钮，或 `Alt+1/2`，或 ⋮ 菜单 → 查看）：

| 模式 | 说明 |
|---|---|
| **详情列表**（Alt+1） | 经典五列表格：名称、大小、修改时间、类型、权限，表头点击排序，大目录虚拟滚动 |
| **大图标**（Alt+2） | 访达式图标网格：13 类文件类型图标（蓝紫渐变拟物风，含 PDF 与可执行/安装包，16px 用简化变体），`Ctrl+滚轮` 在 48/64/96/128 四档间切换大小 |
| 画廊 | 缩略图墙。**暂未开放**：缩略图管线已就绪，待覆盖面达标后放开 |

大图标模式的特性：

- **图标可自由摆放**：直接拖动图标到网格空位，位置按目录记忆（重启、重开标签都保留）；右键空白处「整理图标」恢复自动排列，「自动排列」开启后忽略摆放记录。位置集中存储在应用数据目录（不往被浏览的目录写文件），SFTP 远程目录同样支持。
- **拖动即传输**：拖到文件夹图标上=进入该目录（默认复制，按住 `Alt` 切换移动，悬停时文件夹高亮）；拖到另一个窗格=跨窗格复制/移动（与详情视图一致）；也能直接**拖出到访达 / 资源管理器或浏览器上传区**。
- **键盘**：方向键在网格上移动选择，`Enter` 打开，`Space` 加选；单击选中、双击打开、慢速双击重命名——与详情视图一致。
- **右键空白处**可切换排序方式与图标大小；框选、`Ctrl+A` 全选、反向选择同样可用。
- **长文件名**：默认两行省略；选中或悬停时格子下方浮出全名卡（最多 4 行）。

已知边界：图片/PDF/视频/文档的内容缩略图仅本机目录生效，SFTP 远程目录显示类型图标。

## 预览与图文浏览（v0.28+）

**预览栏**是右侧的一条悬浮拉门：不挤压文件列表布局，全应用共用一个（跨标签、跨分屏窗格），内容跟随焦点窗格的选中项。

- **开启**：点文件不会直接预览。先到 **设置 → 预览 → 启用预览栏**（默认关），之后 `Space`（空格）随时展开/收起；收起后右缘只剩一个贴边把手，点击把手或再按空格拉出。键位可在 设置 → 预览 里改。
- **形态**：拖动左缘可调宽（280–720px），宽度与展开状态自动记忆；命令面板（`Ctrl/⌘+K`）也有「预览栏（展开 / 收起）」。
- **按类型预览**：
  - **图片**：大图适配显示；滚轮以光标为中心缩放、拖拽平移、双击切换 100%/适配；GIF 保持动画；>30MB 大图回退为缩略图放大。
  - **文本**：txt/md/log/ini 之外，代码与数据格式（json/yaml/toml/xml/html/css/sh/py/rs/sql/csv/tsv…）、点文件与约定名（`.gitignore` / `.env` / `.bashrc` / Makefile / Dockerfile / LICENSE…）均可预览（v0.30）；UTF-16（LE/BE）自动识别解码；超过 256KB 渲染前 256KB 并提示（读取上限 2MB）；非 UTF-8 文件会提示。
  - **PDF/Office**（doc/xlsx/ppt 等）：显示首页缩略图 + 元信息，配合「外部打开」查看全文。
  - **远程文件**（v0.31.1）：SFTP 文件显示信息卡 + **「下载到本地并打开」**按钮；HTTP 文件提供「在浏览器中打开」；底部「外部打开」对 SFTP 文件标为「下载并打开」。
  - 其他类型：显示信息卡（图标 + 大小 + 时间）。
- 文件被删除/改名后预览自动更新（目录内容监视）。

**图文浏览模式**适合图片/文档为主的目录，从预览栏底部「浏览 »」按钮或 `Ctrl/⌘+Shift+E` 进入：

- 暗色沉浸背景覆盖侧边栏与文件区（工具栏/状态栏保留），中央显示当前项大图。
- 底部横向缩略图条：图片显示缩略图、文档显示「图标+文件名」小卡，可滚轮横移/点击跳转，只收录可预览类型，排序与文件列表一致。
- 键盘：`←→↑↓` 切换、`Home/End` 首尾、`Enter` 外部打开、`Esc` 退出。浏览即选中：退出后回到原视图，选中停留在当前文件。

注意：预览启用后 `Space` 的语义变为「开/收预览」，列表/图标网格里的空格加选随之让位（未启用预览时行为不变）。

## 标签页

- `Ctrl/⌘+T` 新建；`Ctrl/⌘+W` 关闭；`Ctrl+Shift+T` / `⌘+Shift+T` 恢复刚关闭的标签。
- `Ctrl+Tab` / `Ctrl+Shift+Tab` 循环切换；`Ctrl/⌘+1..9` 直接跳转。
- 鼠标按住标签左右拖动可调整顺序；中键点击关闭；双击标签重命名。
- **右键单个标签**：关闭 / 重命名 / 移到最右 / 关闭其他标签页 / 关闭右侧标签页。
- **右键标签栏空白处**：新建标签页 / 恢复关闭的标签页 / 全部标签页…。
- 窗口较窄时标签自动压缩、标题截断为省略号；「全部标签」下拉（☰）可查看全部标签、点击切换、行内关闭。

## 彩色标签与快速访问

- **Finder 风格彩色标签**：右键文件 / 文件夹 →「标签」组选颜色，文件名左侧出现色点，持久化。内置 7 个预设；**自定义标签**：悬停侧栏「标签」分组名，右侧浮出 **+**，选颜色、起名字即可新增（14 色色板，输入框自动聚焦），总数上限 **10 个**（含预设），加满后再点 + 会提醒。
- **标签视图（`tags://` 虚拟目录）**：点击侧栏彩色标签进入，横幅显示标签名称与颜色，列出该标签全部条目。条目右键：定位 / 打开 / 加标签 / **重命名本体**（v0.31.0 起，含文件夹；改名后指向旧路径的标签与快捷访问自动跟随迁移）；HTTP 条目的「重命名显示名…」改的是**显示别名**（autoindex 只读，本名不变）。
- **快速访问**：右键文件 / 文件夹 →「添加到快速访问」，侧栏出现入口（中键开新标签），上限 **10 条**，加满会提醒；侧栏快速访问条目右键「**重命名显示名…**」可改别名（v0.31.1，任何路径均可）。

## 分屏

- `Ctrl/⌘+\`：左右分屏；`Ctrl/⌘+J`：上下分屏；可反复递归分割成四宫格甚至更多。
- 拖动窗格间分割条调整比例（0.1–0.9），`Ctrl+0` / `⌘+0` 一键重置为均分。
- `Ctrl+Shift+\` / `⌘+Shift+\`：聚焦下一窗格；`Ctrl+Shift+W` / `⌘+Shift+W`：关闭当前窗格。
- **窗格交换**（v0.30）：按住任意窗格顶部的路径头拖到另一窗格，出现「⇄ 交换到此处」徽标，松手即对调两窗格位置（路径/选中/历史整体跟随）；拖回原位或 Esc 取消。
- 每个窗格独立导航、历史、排序、视图模式与选中状态，属性栏显示当前窗格选中项；窗格头路径条可在该窗格内导航或单独关闭窗格。

## 比对功能总览与选型

R-Dir 有三个互补的比对功能，按「比什么」分层——目录级看**哪些条目不同**，文件级看**一行一行差在哪**：

| | 差异比对（v0.17） | 同步比对（v0.18） | 文本比较（v0.19） |
|---|---|---|---|
| 粒度 | 目录级，条目列表 | 目录级，条目列表（实时） | 文件级，逐行左右对照 |
| 对象 | 两个**本地**目录 | 两个路径窗格（本地↔SFTP↔SFTP；HTTP/标签视图不参与） | 任意两个文件（本地 / SFTP / HTTP） |
| 深度 | 三层可选：名称 / +大小 / +内容 hash+时间戳 | 当前层名称/类型+大小（非递归），SFTP 钳制到二层 | 行级 Myers 对齐，超限退化整块粗对齐 |
| 时机 | 静态快照，点「重新比对」刷新 | 实时：随导航防抖 120ms 自动重算 | 打开时一次 |
| 写操作 | **可同步**：多选差异向左/向右覆盖复制+删除 | 只读（唯一远程写入 =「在对侧新建并进入」） | 只读 |
| 入口 | 工具菜单 / 空白处右键 | 工具栏链接按钮 / 菜单 / 状态栏摘要段（Ctrl+Shift+X） | 文件右键「比较」组 / 同步列表双击 / 「工具 → 打开 Git Diff…」/ .patch 右键 |

**怎么选**：

- 要把 A 目录对齐到 B、把差异真正同步过去 → **差异比对**（三者中唯一能动手同步的）；
- 两边目录开着、边浏览边盯有没有漂移 → **同步比对**（开着不用管，自动跟随重算）；
- 看"这两个文件内容到底差在哪一行"（代码 / 日志 / 配置）→ **文本比较**。

**三者联动**：同步比对结果列表里双击两侧同在的文件行，直接落到该对同名文件的文本比较（免基准）；差异比对承担 hash 深比对与目录同步；文本比较支持跨窗格「设为比较基准 / 与基准比较」（基准芯片常驻状态栏），也可粘贴 git diff 直接渲染。

## 差异比对与同步浏览（v0.18）

**同步比对（状态栏入口 + 结果模态）**——边浏览边比对，适合快速巡检两个目录：

- 入口：工具栏链接按钮 / 菜单「工具 → 同步比对」/ 窗格空白处右键。要求当前标签**恰好两个路径窗格**（本地↔本地、本地↔SFTP、SFTP↔SFTP 均可；HTTP 索引与标签视图不参与）。再次触发同一入口即断开。
- 开启后文件列表高度不变，状态栏右侧（「分享」旁）出现实时摘要段：`21 项 · 5 差异` / `一致` / `比对中…` / `未对齐` / `比对失败`；**点击或 `Ctrl+Shift+X`（⌘⇧X，可在设置改键）打开结果模态**，模态随导航实时更新，`Esc` / 遮罩空白 / X 关闭。
- **同步浏览**：开启时两侧当前目录成为映射锚点；一侧进入子目录，另一侧自动进入同名相对子目录（前进/后退、定位等所有导航方式均联动）。对侧没有同名目录时，对侧停在原地，状态栏摘要变琥珀色「未对齐」，模态顶部横幅可一键「在对侧新建并进入」或「返回对齐」。
- **实时比对**：模态内提供「只看差异 / 交换左右 / 重新对齐 / 断开链接」；比对只针对当前层（名称/类型 + 大小，无递归）。SFTP 参与时最多比对到大小（不做远程内容 hash），层级由后端能力自动钳制。
- **内联标注**：链接期间文件列表行首显示细色条——琥珀=仅本侧有、天蓝=仅对侧有、红=两侧都有但不同（悬停看原因与两侧大小）；表头「名称」旁的链接图标标识该窗格已加入比对。
- 链接**按标签生效**（可多标签各自开启）、不随会话保存；关闭任一链接窗格会自动断开。

**差异比对窗口（工具 → 差异比对…）**——两个本地目录的静态深比对：三层可选手动开（名称/大小/内容 hash + 时间戳），支持进度与中途停止、只看差异、多选后向左/向右同步（覆盖复制与删除）。

## 文本比较与 Git Diff（v0.19）

**任意两文件的文本比较**——比内容行，适合代码、日志等文本文件：

- 右键文件 →「比较」组：
  - **设为比较基准**：把该文件记为基准（状态栏出现基准芯片，× 清除；右上角窗格列表给基准所在窗格加标记点）。再点一次取消。
  - **与基准比较**：在**任意窗格**右键另一文件直接比较（跨标签、跨后端均可）。未设基准时该项置灰并提示。
  - **与另一文件比较…**：弹出窗格选择器——左列是所有已连接窗格，右列是所选窗格**当前目录**的文件（直接读内存列表，零 IO），可按名称过滤；底部支持直接粘贴任意路径（本地 / `sftp://` / `http(s)://`）。
  - 同目录多选两个文件 → **比较所选两个文件**。
  - 设为/清除基准时，状态栏右下角会短暂提示；芯片常驻可随时 × 清除。
- **同步比对结果模态联动**：结果列表里，两侧同在的文件行**双击**（或悬停行点击比较图标）即可直接文本比较同名文件，**无需设基准**；仅单侧存在或类型冲突的行不可比较。
- **Git Diff 直接打开**：`.patch` / `.diff` 文件右键 →「查看 Diff」；菜单「工具 → 打开 Git Diff…」可粘贴 `git diff` 输出直接渲染（支持多文件段落、容忍 CI 日志前后文噪音）。纯文本解析，**不要求本机安装 git**。
- **窗口形态**（v0.29+）：文本比较（1400px）与目录差异（1280px）窗口**打开即近全屏**；`F11`（macOS 亦可用 `⌘⇧F`，F11 默认被系统「显示桌面」占用）在窗口内切换最大化/还原；左右双栏**恒各半屏**，超长行在栏内截断、悬停 title 看全文。
- 渲染与操作：左右双栏行号，删除行红 / 新增行绿；长相同段折叠为「⋯ 已折叠 N 行 — 点击展开」（保留 ±3 行上下文）；「只看差异」隐藏全部相同行；最大化 / `Esc` 关闭；虚拟滚动支撑大文件。
- 范围与限制：单文件 ≤ 8MB；二进制（含 NUL 字节）拒绝比较；非 UTF-8（如 GBK）按替换符显示并在头部提示（显式编码选择支持 UTF-16）；`\r\n` 归一；结尾换行符差异忽略；差异过大时退化为整块替换粗略显示（头部横幅提示）。SFTP/HTTP 文件自动下载到临时目录比较（用后即删），SFTP 两侧同名文件不会相互覆盖。

## 搜索

`Ctrl+F` / `⌘+F` 打开并聚焦"文件名"；`Ctrl+Shift+F` / `⌘+Shift+F` 切到"内容"；工具栏搜索按钮与 ⋮ 菜单均可。v0.29 起搜索为**居中模态框**（640px × 70vh）：点遮罩 / `Esc` / 右上角 × 关闭，递归检索的长路径与内容搜索的「路径 + 行号 + 命中行」有完整展示宽度。

**文件名 tab**
- 默认仅搜索当前层，实时过滤文件名。
- 输入框下方一排**灯芯开关按钮**（点击点亮 / 熄灭），两个 tab 同一套语义：
  - **递归**（蓝灯）：递归遍历整个目录树（fd 引擎，尊重 `.gitignore` / `.ignore`），结果上限 500；点击目录直接进入、点击文件跳转定位并关闭模态框。
  - **隐藏**（绿灯）：包含 `.` 开头的隐藏文件 / 目录（默认跳过；等价 fd `--hidden`）。
  - **Aa**（琥珀灯）：区分大小写（默认不区分）。
  - **`.* 正则` / `✱ 通配`**（紫色，点击互换）：文件名按正则（如 `^src/`，默认）或通配符（如 `*.rs`，等价 fd `--glob`）整名匹配；当前层前端过滤遵循同一语义。
- 按钮行下方实时显示当前组合摘要（如 `fd 递归中 · 通配符 · 含隐藏 · 区分大小写 · 尊重 .gitignore`）。

**内容 tab**
- 同一排灯芯按钮：**递归**（蓝）、**隐藏**（绿）、**Aa**（琥珀）、**`.* 正则`**（紫，点亮后查询词按正则解析，默认字面量匹配——与 rg 相反的默认，避免误把普通关键词当正则）。
- 自动跳过二进制、超大（>4MB）与非 UTF-8 文件；结果显示路径 + 行号 + 高亮，点击跳转定位（模态一并关闭），双击外部打开（模态保留，方便连续打开多个结果）。

**结果右键**：定位 / 打开（系统关联）/ 复制相对与绝对路径 / 内联重命名。

## 远程（SFTP）

### 连接与服务器管理

- **四个入口**：地址栏输入 `sftp://` 回车弹连接框（`sftp://user@host:/path` 会把 `/path` 同时预填为「根目录」并在连接后直达）；侧栏「远程服务器」分组名悬停 **+**；⋮ 菜单「工具 → 添加 SFTP 服务器…」；侧栏点击已保存的服务器直连。
- **连接对话框**：名称 / 分组 / 主机 / 端口 / 用户；认证支持**密码**或**私钥**（可带 passphrase，密钥路径留空自动尝试 `~/.ssh/id_*`）；「根目录」为连接后的默认导航位置；**「保存」**只写配置不连接（v0.31.0），「连接」保存并连接。
- **凭据与主密钥**：勾选「记住密码」默认以明文保存在本机配置；⋮ 菜单「工具 → SFTP 主密钥…」设置主密钥时，现有明文密码会立即自动加密（AES-256-GCM），此后连接需输入主密钥解锁（主密钥只驻内存、不落盘）；忘记主密钥可重置（会清除全部已保存密码）。
- **分组整理三件套**（v0.31.0）：侧栏按分组显示服务器；服务器条目**拖到其他分组名上换组**（悬停高亮，落「默认」组=解除分组）；分组名右键「**重命名分组…**」整体改名（显示组内台数）。
- **导出 / 导入服务器列表**（v0.31.0，侧栏分组名右键或 ⋮ 菜单）：导出为可迁移 JSON（含已保存密码的密文）；**存在明文密码时拒绝导出**并引导先设主密钥；导入按 id 去重合并（不覆盖本机已有），文件含密文时需输入**导出方主密码**才能解析。
- **清理远程临时文件**（v0.31.0）：侧栏「远程服务器」分组名右键，先报占用（文件数/字节）再整体清空双击远程文件产生的临时下载目录。

### 浏览与传输

- 远程列表浏览、新建、重命名、删除与本地体验一致（删除文件夹递归）；标签视图里的远程条目重命名会**自动连接**所属服务器（v0.31.1）。
- **上传 / 下载**：拖拽（本地↔远程窗格互拖）或复制粘贴均可；文件夹自动**递归传输**——两阶段进度（先统计总数，再显示「3/17 · sub/dir/file.txt」）；上传走**滑动窗口流水线**（v0.28.1），高延迟链路速度与命令行 sftp 同量级；均有进度条与「停止」，取消不留半成品。
- **同名覆盖**：目标已有同名条目时先弹应用内确认框（`Enter` 确认 / `Esc` 取消）。
- **打开远程文件**：双击自动下载到临时目录后用系统应用打开；预览栏提供「下载到本地并打开」。
- **会话恢复**：重启后恢复布局与远程路径，SFTP 只存服务器 id 不含凭据；已设主密钥的需解锁后自动重连，取消解锁则保留布局不连接。
- 已知边界：SFTP 传输暂不支持断点续传（HTTP 下载支持）；内容预览不支持远程文件（提供「下载并打开」）。

## HTTP 目录（autoindex）

- 地址栏输入 `http(s)://…` 进入 nginx autoindex（HTML）或 JSON 索引目录，列表、排序、快速定位等体验与本地一致。
- 点击目录进入；**双击文件在浏览器在线打开**。
- 把条目拖到本地窗格（或复制粘贴）= 流式下载，带进度条与停止；中断后重新下载自动从 `.part` 文件**断点续传**（v0.6.5）。
- 只读协议：不支持新建 / 删除；「重命名」只改**显示别名**（本名与服务器不变，标签视图与快捷访问同步显示别名；列表 / 网格里直接重命名会提示只读）。

## 目录分享

把当前目录通过 HTTP 分享给他人（收方只需浏览器）：

- **创建**：右键目录 →「分享此目录…」（窗格空白处右键同样入口）。对话框可设：**允许接收方上溯父目录**（默认关，严格锁定分享根内）、**并发连接数上限**（默认 3）、**有效期**（24 小时 / 自定义小时数 / 永久）。创建后展示链接 + **二维码** + 复制按钮，token 即凭证。
- **接收方**：浏览器打开链接即 autoindex 风格目录浏览，下载支持 Range 断点续传。当前分享为**只读**（浏览 + 下载）。
- **管理**：状态栏「分享」按钮打开分享管理面板——活跃分享列表、访问者 IP / User-Agent / 时间日志、一键「停止分享」（链接立即失效）。
- **默认行为**：设置 → 分享 可配置默认的是否允许上溯与默认有效期。

## 快捷键一览与自定义

默认键位（可在 设置 → 快捷键 自定义，支持录制、冲突检测、恢复默认）：

- 导航：`⌘/Ctrl+L` 聚焦地址栏、`Backspace` 返回上级、`F5`（Windows）/ `⌘R`（macOS）刷新、`Alt+←/→`（mac `⌘[/]`）后退/前进
- 文件：`⌘/Ctrl+C` / `X` / `V` 复制 / 剪切 / 粘贴、`F2` 重命名、`Delete` 删除到回收站（macOS 亦可 `⌘⌫`）、`Shift+Delete` 永久删除、`⌘/Ctrl+Z` 撤销、`Ctrl+Y`（Windows）/ `⌘⇧Z`（macOS）重做
- 标签页：`⌘/Ctrl+T` 新建、`⌘/Ctrl+W` 关闭、`Ctrl+Tab` 循环切换、`⌘/Ctrl+1..9` 跳转
- 窗格：`⌘/Ctrl+\` 左右分屏、`⌘/Ctrl+J` 上下分屏、`Ctrl+0` 重置比例
- 视图：`Alt+1/2` 详情/大图标、`Ctrl+滚轮` 缩放
- 预览：`Space` 开/收预览栏（启用后）、`⌘/Ctrl+Shift+E` 图文浏览
- 搜索：`⌘/Ctrl+F` 文件名、`⌘/Ctrl+Shift+F` 内容
- 比对：`⌘/Ctrl+Shift+X` 同步比对结果、`F11` / `⌘⇧F` 比对窗口最大化
- 全局：`⌘/Ctrl+K` / `⌘/Ctrl+Shift+P` 命令面板、`⌘/Ctrl+,` 或 `F1` 设置、`Ctrl+Alt+T` / `⌘+Option+T` 切主题、`Alt+Enter` / `⌘I` 属性栏

菜单栏"帮助"与「设置 → 快捷键」可查看全部动作在当前平台的键位。

## 命令面板

`⌘/Ctrl+K`（或 `⌘/Ctrl+Shift+P`）呼出：模糊搜索全部动作（视图切换、分屏、比对、分享、设置、检查更新……），键位提示跟随自定义键位；右上角 ⋮ 应用菜单平铺全部入口。

## 会话保存与恢复

- **退出确认**：窗口 ×、⋮ 菜单退出、`⌘Q` 等所有退出路径统一弹「保存会话布局？」三选项。
- **保存内容**：标签集合、分屏树（方向 / 比例）、各窗格路径与活动标签、视图模式 / 图标摆位 / 界面偏好；SFTP 窗格只存服务器 id（不含凭据）。
- 启动自动恢复；同步比对链接不随会话保存（重启后需重新开启）。

## 检查更新

⋮ 菜单「帮助 → 检查更新…」基于 GitHub Releases API 比对版本（启动时也会静默检查，有新版时提示）；「GitHub 仓库」直达项目主页。

## 常见问题

- **macOS 打开提示"已损坏"**：执行 `xattr -cr /Applications/R-Dir.app`，或右键应用 → 打开；也可在"系统设置 → 隐私与安全性"中允许。
- **拖拽文件后目标窗格没变化**：确认松开时鼠标在目标窗格内部（提示条出现的位置）；拖到分割条上不会落盘。
- **内容搜索无结果**：默认仅当前层且跳过隐藏/二进制文件；大目录请点亮「递归」灯钮，隐藏内容点亮「隐藏」灯钮。
- **地址栏补全无效**：输入路径前缀后等待约 0.1 秒出现下拉；`Tab` 仅补全不跳转，`Enter` 才跳转。
- **地址栏命令执行报「未找到命令」**：命令需在 PATH（含 macOS 兜底目录，缓存最多 10 分钟后可见新装工具）中存在且可执行；macOS 首次执行需授权控制「终端」；也可在 设置 → 插件 中确认「地址栏命令」已启用。
- **传输失败去哪看原因**：窗口中央红色浮层（3.6 秒）与状态栏均会显示具体原因（只读 / 被占用等）；复制的写入是事务化的，失败不会破坏已存在的目标文件。
- **分享链接不能上传**：当前分享为只读（浏览 + 下载）。
- **SFTP 中断后能续传吗**：SFTP 暂不支持断点续传（重新传输即可）；HTTP 下载支持 `.part` 断点续传。
