# v0.25.0 macOS 真机测试交接方案

本分支（`feat/ui-theme`，v0.25.0）的改动在 Windows + Chromium 环境已全部通过
（前端 393 / e2e 82 / Rust 109），但以下内容只能在 macOS 真机验收。WSL 不适合：
只能覆盖 unix 通用代码路径，且需安装整套 GTK/WebKitGTK 编译依赖；而 macOS 独有逻辑
（launchd PATH 兜底目录、⌘ 键位、WKWebView 时序）WSL 覆盖不到——本版恰好包含一个
**时序敏感竞态修复**（QuickJump Esc），更需要真机多试。

## 准备

```bash
git fetch origin
git checkout main && git pull          # 或直接 checkout tag v0.25.0
pnpm install
pnpm tauri dev
```

## 测试清单（按优先级，逐项记 pass/fail）

### A. 地址栏补全：首卡与索引（本版性能修复重点）
- [ ] 启动后立即可用：`~/Library/Application Support/com.rfm.app/cmd-index.json` 生成（首次启动后台生成；可在 Finder 按 `⌘⇧G` 跳转）
- [ ] `⌘L` 聚焦地址栏，**首次**输入裸词（`git` / `node` / `pnpm`）——下拉应立即/近立即出现，**不应有可感知卡顿**
- [ ] 命令分组含 homebrew 目录条目（如 `/opt/homebrew/bin/git`）——验证 macOS 兜底目录扫描
- [ ] 往 PATH 目录放一个可执行文件（如 `printf '#!/bin/sh\n' > /usr/local/bin/rdir-test && chmod +x /usr/local/bin/rdir-test`）→ **最迟 10 分钟**后输入 `rdir` 出现该项；期间操作全程无卡顿
- [ ] 删除该文件 → 同样最迟 10 分钟内消失，期间无感（哨兵检测 + 后台重建，不应出现 UI 冻结）
- [ ] 重启应用：不重新扫描（索引已持久化），输入裸词依然即时

### B. 补全 scheme 门控
- [ ] 输入 `http://` / `https://` 开头 → 不出现补全下拉，无报错
- [ ] 输入 `sftp://` 开头、该服务器**未连接** → 不出现补全
- [ ] 连接一个 sftp 服务器后（已连接窗格内），地址栏输入 `sftp://<host>/` 继续输入 → 出现远程目录补全（仅目录；每级继续可补）
- [ ] 输入 `tags://` → 不出现补全

### C. 窗格头路径层（新功能）
- [ ] 单窗格：列表上方有路径条，分段之间雪佛龙分隔
- [ ] `⌘\` 左右分屏 / `⌘J` 上下分屏 → 两个窗格**各有**路径条，右侧各有关闭钮
- [ ] 非活动窗格的路径条文字弱化（灰），活动窗格正常（黑/白）
- [ ] 点击某窗格路径条上的段 → **该窗格**跳转并激活（地址栏跟随）
- [ ] 点击路径条右侧 × → 只关闭对应窗格（剩单个窗格时无 ×）
- [ ] `⌘⇧\` 循环切换窗格焦点、`⌘⇧W` 关闭当前窗格
- [ ] 标签视图（tags://）不出现路径条，原横幅不变

### D. 地址栏彩虹分段
- [ ] 地址栏路径分段彩虹配色显示正常（淡彩、箭头形分段），明暗主题下都可读
- [ ] 点击段跳转、末段加粗、悬停变亮等原有交互不变

### E. 快速定位（QuickJump）Esc 竞态（本版修复，需多试）
- [ ] 列表聚焦后键入字母 → 实底浮层弹出（带阴影、非透明玻璃），命中字符高亮
- [ ] ↑↓ 或鼠标悬停移动高亮，背后列表实时跟随选中滚动
- [ ] **Esc → 浮层关闭且打开前的选中仍在（蓝色底 + 名称加粗 + 内环）——重复 ≥10 次**
      （此前约 1/12 概率选中被清空/跳到别的行，本版已修）
- [ ] 回车：文件定位选中 / 目录直接进入
- [ ] 点浮层外：关闭且不还原选中（保持这个既有语义）

### F. 主题视觉
- [ ] `⌘⌥T` 或右上角太阳/月亮按钮切换明暗：蓝色品牌色、冷灰表面切换正常
- [ ] 活动标签顶部有 2px 蓝色条；选中文件行为蓝色底 + 加粗
- [ ] 设置（`⌘,`）弹窗：卡片底色比页面略亮（暗色下）、圆角与阴影协调
- [ ] 状态栏/侧栏/搜索面板表面色一致（比背景略灰的 sidebar 色）

### G. mac 历史功能回归（改动的相邻面）
- [ ] `⌘Q`：弹出「保存会话布局？」确认框（取消后应用仍运行）
- [ ] 鼠标侧键（如鼠标有）：后退/前进可用（WKWebView 走 mouseup 路径）
- [ ] 刷新 `⌘R`、上级 `⌘↑`、⌘1-9 跳标签正常

## 反馈方式

- 逐项标 pass/fail；fail 项贴：复现步骤 + 截图 + 控制台报错（开发窗口终端输出）
- 若 A 组出现卡顿：在卡顿时抓一次 `sample <pid> 1 -mayDie` 或 Activity Monitor 截图，能直接看出是否仍在主线程扫描
