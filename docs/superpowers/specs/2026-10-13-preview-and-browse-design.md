# 设计稿：文件预览栏 + 图文浏览模式（v0.28.0）

- 日期：2026-10-13
- 版本：v0.28.0
- 状态：已批准（用户对齐 ASCII 图示后定稿）

## 目标

为图片与文档类文件提供应用内预览，不改变「双击 = 外部打开」的现有习惯：

1. **预览栏（右侧拉门）**：覆盖式浮层，悬浮在内容区上方（不挤压分屏布局），
   全应用共用一个，跨标签、跨分屏窗格，内容跟随焦点窗格的选中项。
2. **图文浏览模式**：在图片/文档为主的目录进入沉浸式浏览，中央大图 +
   底部横向缩略图条，文档以「图标 + 文件名」小卡参与。

预览**不是**点击即预览：必须先在设置 → 预览里开启总开关（默认关），
之后用快捷键（默认空格）随时展开/收起。

```
│ 下载     │   图 photo-02.jpg  2.1 MB  10-11     ┃ ║                       ║ ┃ │
│ 图片     │   图 photo-03.jpg  800 KB  10-10     ┃ ║    图片 · 适配显示     ║ ┃ │

│          │   文 todo.md       1 KB    10-06     ┃ 缩放   -  100%  +         ┃ │

```

- `┃` = 浮层左边界：预览栏悬浮在文件列表之上，列表布局不被挤压。
- 选中变化（点选 / 方向键）→ 预览即时切换（缩略图/内容走缓存，切换流畅）。
- 右缘 `»` = 收起按钮。

## 交互规格

1. **开启**：点文件不直接预览。设置新增「预览」分区，总开关默认关（含键位）。
   开启后右侧滑出拉门，此后 `空格`（默认，可改）随时展开/收起；命令面板同步
   出现「切换预览栏」「图文浏览模式」。输入框聚焦时空格不受影响
   （复用 keymap 的 typing 放行逻辑）。
2. **形态**：覆盖式拉门，z 层在内容之上、对话框之下（z-40 < Dialog z-50）；
   高度介于工具栏与状态栏之间（挂在内容行容器内 absolute 定位）；
   默认宽 360px，左缘拖拽调宽 280–720px；宽度/展开/收起状态记忆（localStorage）；
   开合约 200ms transform 滑动；收起 = 贴边细把手（右侧居中竖条）。
3. **共用**：全应用一个预览栏，跨标签、跨分屏窗格，内容跟随焦点窗格选中项
   （`activePane.selection[0]`）；未选中/选目录显示占位提示。
4. **按类型**：
   - 图片：大图 fit 适配 + 滚轮以光标为中心缩放 + 拖拽平移 + 双击切 100%/适配；
     GIF/静态图走 `preview_data` 原字节（保 GIF 动画），>30MB 回退缩略图放大并提示。
   - txt/md/log/ini/conf/env/gitignore：`read_text_file` 文本渲染（2MB 上限），
     非 UTF-8 显示 lossy 提示。
   - PDF/Office（doc/sheet/slide）：首页缩略图（`thumb_get`，QuickLook 管线）
     + 名称/大小/修改时间 + 「外部打开」，不渲染正文（pdf.js 留后续版本）。
   - 其他类型 / 远程（sftp://、http://、tags://）：信息卡（图标+元信息+外部打开）+
     「此类型暂不支持预览 / 远程文件暂不支持内容预览」提示。
   - 头部：类型图标 + 文件名 + 收起按钮；底部操作条：外部打开、浏览 »（仅目录内
     存在可预览条目时可用）。
5. **图文浏览模式**：
   - 入口：预览栏底部「浏览 »」按钮 + `toggleBrowse` 快捷键（默认 mod+shift+e）。
   - 覆盖侧边栏+文件区（工具栏/状态栏保留，挂内容行容器 absolute inset-0），暗色背景。
   - 条目清单 = 焦点窗格条目经 `sortEntries`（与列表同序、遵循隐藏开关）后过滤可预览类型
     （image/text/pdf/doc/sheet/slide），目录不参与。
   - 中央：图片 → ImageView；文本 → TextView；文档 → 首页缩略图卡。
   - 底部缩略图条：图片 = ThumbImage 懒加载卡；文档 = 图标+文件名小卡；当前项高亮，
     自动滚动居中；滚轮横滚。
   - 键盘（capture 捕获，避免落回全局分发）：←/→（含 ↑/↓）切换、Home/End、
     Enter 外部打开、ESC 退出。其余组合键放行全局分发。
   - 导航即选中：onNavigate(i) → `selectRange(paneId, [path])`，预览栏/中央区/
     列表选中三方同步；退出后原视图停留在当前文件。

## 按子系统分节

### Rust（src-tauri）

- 新模块 `preview.rs`：`preview_data(path) -> Result<Option<String>, String>`。
  仅本地绝对路径；扩展名白名单 png/jpg/jpeg/gif/webp/bmp/tiff/tif（按 mime 回原字节，
  保 GIF 动画）+ svg（原字节 image/svg+xml）；>30MB 或读取/非文件 → Ok(None)
  （前端回退缩略图/信息卡）。base64 data URL，spawn_blocking 不卡主线程。
  不启用 asset protocol、不改 capabilities（沿用 v0.27 设计决策）。
- 注册进 lib.rs 的 generate_handler!（覆盖语义，必须合并进同一宏）。
- 首页缩略图复用 `thumbs::thumb_get`；文本复用 `read_text_file`；无其他后端改动。

### 前端

- `src/lib/persist.ts`：`rfm.preview`（enabled / expanded / width）load/save 三对函数。
- `src/lib/keymap.ts`：新增 `togglePreview`（win/mac 均为 `space`）、
  `toggleBrowse`（`mod+shift+e`），group「视图 / 全局」→ 命令面板/设置键位区自动出现。
- `src/lib/api.ts`：`previewData(path)`。
- `src/components/preview/ImageView.tsx`：缩放（滚轮以光标为中心，0.1–10）+ 拖拽平移
  + 双击切 100%/适配；路径变化重置视图；onload 记录自然尺寸算 fitScale。
- `src/components/preview/TextView.tsx`：readTextFile + 大小门控 + lossy 提示。
- `src/components/preview/DocCard.tsx`：ThumbImage(512) + 元信息 + 外部打开。
- `src/components/preview/PreviewBody.tsx`：按 kind 分发到上述视图 + 信息卡/占位。
- `src/components/PreviewDrawer.tsx`：拉门容器（expanded 面板 / 收起把手 / 左缘拖宽）。
- `src/components/BrowseMode.tsx`：沉浸壳 + 中央 PreviewBody 复用 + 缩略图条
  （ThumbImage 懒加载）+ capture 键盘导航。
- `src/components/SettingsDialog.tsx`：新增「预览」分区（总开关、两个键位的录制行、
  默认宽度滑杆 280–720）。
- `src/App.tsx`：状态 `previewOn/previewExpanded/previewWidth/browseOpen` +
  actionsRef 分发 `togglePreview/toggleBrowse` + 布局挂载（内容行容器内）。
  browse 键盘由 BrowseMode capture 层处理，App 全局分发不感知。

## 已知边界

- 远程文件（sftp/http/tags）不做内容预览（信息卡 + 提示）；下载链路后续版本再接。
- PDF/Office 仅首页缩略图；不做 pdf.js 正文渲染。
- heic/avif/ico 图片后端不解码（image crate 特性面限制），显示信息卡。
- 原图 >30MB、文本 >2MB 走回退路径；GIF 大于上限回退为静态首页缩略图。
- Windows 端 PDF/Office 首页缩略图依赖现有 ql 桩（返回 None → 图标回退），
  图片预览不受影响。
- 预览栏为覆盖式浮层：展开时遮住右侧约 1/3 内容，需要操作被遮区域时先收起
  （空格 / 点把手 / »）。
