## 已知问题与平台兼容性坑（⚠️ 排障必读）

### 已解决（v0.6.2）

1. **右键加标签不生效 + 标签视图无内容 + ＋ 新建标签页无效**（5.1/5.2/5.3/1.1）：
   - **根因**：macOS WKWebView 上 **Radix ContextMenu 子菜单（`ContextMenuSub`）的菜单项点击事件丢失**——右键"标签"子菜单内的选项 onClick/onSelect 均不触发。v0.6.1 为修右键重命名引入 `modal={false}` 后恶化，子菜单点击完全失效（直接菜单项如"删除/打开"正常，仅 Sub 内项失效）。
   - **修复**（v0.6.3 临时）：右键菜单**不再使用子菜单（Sub）**——"标签"六个颜色、"打开方式"列表、"在此处打开终端"的 shell 列表全部**平铺在父菜单第一层**；行菜单 `modal` 恢复默认（true）。**v0.10.0 起用「同级内联展开」实现折叠，仍不使用 Radix Sub，见文末「已解决（v0.10.0）」第 4 条。**
   - **验证**：右键文件→标签→红色→文件名左侧出现色点 ✅；左侧栏点红色进入标签视图 ✅；＋新建标签页 ✅。
2. **启动黑窗/加载慢**（已修）：v0.6.2 增加 backgroundColor + 首屏分批加载，回归时验证启动无黑窗、默认目录快速加载。
3. **macOS 首次打开"已损坏"**（已缓解）：adhoc 签名 + README 说明；彻底解决需开发者证书公证。

### 已解决（v0.10.0）

4. **WKWebView（macOS）上右键菜单二级折叠**（5.1/7.2/7.3）：不再用 Radix 子菜单，改为**同级内联展开**。
   - **根因**：Radix `MenuSubContent` 在 Tauri WKWebView 下子项点击丢失（一级菜单正常、二级能弹出但点项无反应）。Radix 官方 issue #4095 给出的 `onFocusOutside={(e) => e.preventDefault()}` workaround 在本项目真机实测**无效**；Playwright 的 Chromium/WebKit 也复现不出（有无该修复都通过），故只能换实现。
   - **方案**：新增 `src/components/MenuGroup.tsx`——组名是一个 `ContextMenuItem`，`onSelect` 里 `preventDefault()` 阻止菜单关闭，再切换展开态，子项内联渲染在同级菜单里。完全不依赖 Radix `MenuSub`，复用的正是能正常工作的扁平菜单结构。
   - **应用**：行右键菜单的「打开方式 / 在此处打开终端 / 压缩为 / 标签」；空白处右键菜单的「在此处打开终端」。`FileList` 用 `expandedMenu` 状态管理，菜单关闭时重置。
   - **验证**：`src/components/MenuGroup.test.tsx`（去掉 `preventDefault` 即红）；macOS 真机右键→标签加色点、打开方式→选择其他应用、终端、压缩。
   - **教训**：macOS 目标下**不要用 Radix 嵌套子菜单**（`ContextMenuSub`/`DropdownMenuSub`）。要分层就内联展开或自绘 popover。
- **`modal={false}` 是高风险开关**：改它影响菜单点击/焦点/关闭行为，改动后必须回归验证所有菜单项点击（尤其嵌套菜单）。当前仅空白处右键菜单保留 `modal={false}`（其项均为直接项，已验证）。

## 建议的每次发布前回归流程

1. 启动应用：无黑窗、默认目录 3s 内加载
2. 标签页：＋新建 → Cmd/Ctrl+T → Ctrl+Tab 切换 → 拖拽排序 → 关闭
3. 分屏：左右/上下 → 拖分割条 → 跨窗格拖拽复制 → 中键目录开新标签
4. 导航：地址栏输入/补全 → 后退/前进/上级 → F5 刷新 → 快速定位（2s 淡出）
5. 文件：矩形框选 → 多选 → 复制/剪切/粘贴 → 删除（文件夹弹确认）→ 撤销 → 新建文件夹/文本 → 慢速双击重命名 → 右键重命名
6. 标签：加红色标签（见色点）→ 左侧栏点红色 → 标签视图点击条目进入目录
7. 快捷访问：添加 → 点击进入
8. SFTP（如启用）：连接 → 浏览 → 下载 → 会话恢复（master-key）
9. 主题切换、快捷键设置、隐藏文件、搜索面板、属性栏
10. 菜单栏：点击"文件"打开 → 悬停"编辑"切换 → 点击空白关闭；再悬停"文件"不自动打开
