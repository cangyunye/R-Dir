# R-Dir 回归测试手册（REGRESSION.md）

> 本文件是发版前的**手测清单**。每次发版前，按本表逐条过一遍，任何一条不过则不得发版。
> 自动化测试（`pnpm test`）已覆盖部分纯函数逻辑，但以下流程必须人工确认 UI 行为。

## 版本基线

当前稳定基线：**v0.8.0**（初始稳定版）+ **v0.8.1**（SFTP 刷新修复）+ **v0.8.2**（测试基建）。

---

## 0. 环境准备

### Windows 测试环境
- 操作系统：Windows 10/11
- 已安装：R-Dir 最新安装包（`R-Dir_x.y.z_x64-setup.exe`）
- WSL：已开启远程登录（`sudo service ssh start`），用于 SFTP 测试
  - 连接信息：`sftp://<wsl-user>@localhost:22`（或 WSL IP）
  - 测试密钥：`~/.ssh/id_ed25519`
- nginx：已配置 autoindex，指向本地目录（如 `F:\图书馆和资料`），监听 `http://localhost:8082/`

### macOS 测试环境
- 操作系统：macOS 12+（Apple Silicon / Intel）
- **macOS 上 Playwright E2E 暂不自动跑**，需人工按本清单回归
- 首次打开需执行：`xattr -dr com.apple.quarantine /Applications/R-Dir.app`

## 3. 插件回归

### 3.1 SFTP 插件（feature: sftp）
- [ ] 左侧远程服务器列表可添加新连接
- [ ] 密码登录：输入 host/port/user/password 可连接
- [ ] 密钥登录：留空 keyPath 可自动探测 `~/.ssh/id_*`
- [ ] 路径栏输入 `sftp://` 可弹出空白连接框
- [ ] 路径栏输入 `sftp://user@host:port/path` 已连接时直接进入
- [ ] 主密码（master-key）设置后，连接需输入主密码
- [ ] 主密码忘记：MasterKeyDialog 底部"忘记主密钥？"可重置，重置后所有保存密码失效
- [ ] 会话保存：退出时选"保存并退出"，重开后布局和路径恢复
- [ ] SFTP 会话恢复：已连接服务器重开后自动连接（需主密码验证），未验证时保留布局不连接
- [ ] SFTP 已连接后，文件列表正确刷新（**回归点**：v0.8.1 修复）
- [ ] 本地文件拖到 SFTP 上传成功，不报"文件不存在"（**回归点**：v0.8.8 修复）
- [ ] SFTP 目录右键删除文件夹可用
- [ ] SFTP 连接可分组管理

### 3.2 分享插件（feature: share）
- [ ] 右键目录 → 分享此目录
- [ ] 分享对话框：只读/可写/删除权限、连接数上限
- [ ] "打开验证"在系统浏览器中打开链接
- [ ] 浏览器打开可浏览目录、下载文件
- [ ] 可写权限下可上传（同名自动改名）
- [ ] 分享有有效期设置（默认 24h，永久到关闭客户端）
- [ ] 主动停止分享

### 3.3 HTTP autoindex 插件
- [ ] 地址栏输入 `http://localhost:8082/` 可浏览 nginx 目录

## 6. Playwright E2E 方案确认

### 6.1 目标
覆盖手测清单中**最容易回归、最高频**的 10 条关键路径，发版前在 Windows 上自动跑。

### 6.2 技术选型
- **Playwright**：驱动 Tauri WebView（`@playwright/test`，`webView: true`）
- **测试框架**：`@playwright/test` runner
- **SFTP mock**：Windows 本地 WSL OpenSSH 服务器（`localhost:22`），预生成测试密钥
- **HTTP mock**：本地起 nginx（或 Python `http.server` + 自写 autoindex HTML）
- **CI 集成**：GitHub Actions 新增 `e2e` job（仅 windows-latest），macOS/Linux 暂不跑

### 6.3 E2E 用例清单（P0 = 阻塞发版）

| # | 用例 | 步骤 | 预期 | 优先级 |
|---|---|---|---|---|
| E1 | 启动无黑窗 | 启动 R-Dir，截图首屏 | 无黑色闪烁，飞鸟动画后见文件列表 | P0 |
| E2 | 默认目录加载 | 启动后等 2s | 文件列表非空，无"加载中"卡死 | P0 |
| E3 | 导航：前进/后退 | 进入子目录→后退→前进 | 路径正确切换 | P0 |
| E4 | 标签新建/关闭 | 点＋新建标签，中键关闭 | 标签数变化正确 | P0 |
| E5 | 分屏 Ctrl+J | 按 Ctrl+J | 出现两个窗格 | P1 |
| E6 | 虚拟滚动完整性 | 打开上千文件目录，不滚动 | 首屏 ≥15 行（**回归：曾只 6 行**） | P0 |
| E7 | 矩形框选 | 在文件列表拖拽出矩形 | 被框中的文件高亮选中 | P1 |
| E8 | SFTP 连接 WSL | 地址栏输 `sftp://u@localhost/`，输主密码 | 远程目录列出 | P0 |
| E9 | 本地→SFTP 上传 | 从本地拖文件到 SFTP 窗格 | 进度条完成，SFTP 出现文件（**回归：曾报"文件不存在"**） | P0 |
| E10 | HTTP autoindex | 地址栏输 `http://localhost:8082/` | 列出 nginx 目录内容 | P1 |

### 6.4 不在 E2E 范围（人工测）
- 拖拽复制进度条视觉确认
- 分享插件的浏览器端交互（需另起 Web 端测试）
- 主题切换视觉
- 压缩进度条
- macOS 全部用例（mac 机器暂不自动跑）

### 6.5 实施步骤（确认后执行）
1. `pnpm add -D @playwright/test`
2. 新建 `e2e/` 目录，写 `playwright.config.ts`
3. 写 E1-E10 用例
4. CI 加 `e2e` job（windows-latest，起 WSL sshd + nginx）
5. 本地 `pnpm e2e` 跑通后，合入主分支
