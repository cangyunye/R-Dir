# R-Dir 自动化测试场景用例（评审稿）

> 本文档列出所有需要自动化/手动回归的测试场景，按功能模块分组。
> P0 = 阻塞发版，P1 = 重要，P2 = 次要。
> 确认后开始写 Playwright E2E 用例。

---

## 1. 启动与窗口

| ID | 场景 | 步骤 | 预期 | 优先级 |
|---|---|---|---|---|
| W1 | 启动无黑窗 | 启动 R-Dir | 浅色窗口直接出现，无黑色闪烁 | P0 |
| W2 | 开屏动画 | 启动后观察 2 秒 | 飞鸟从左滑到右，1.2s 后淡出 | P1 |
| W3 | 默认目录加载 | 启动后等 2s | 默认目录（主目录）文件列表非空 | P0 |
| W4 | 字体大小 | 新安装/清 localStorage 后启动 | 字体为 15px（非 13px），界面不缩小 | P0 |
| W5 | 老用户字体迁移 | localStorage 存 rfm.ui-font=13，启动 | 自动迁移到 15px，不再显示小字 | P0 |
| W6 | 菜单栏 hover | 鼠标点"文件"菜单，移到"编辑" | "编辑"菜单自动展开，不需要再点 | P0 |
| W7 | 菜单栏点击后移动 | 点"文件"展开后移到"查看" | "查看"自动展开 | P0 |
| W8 | 检索是否有上次会话自动打开上次会话 | 启动后观察 | 无论是布局还是目录还是sftp或者nginx都可以打开，只有sftp输入正确主密码或者有密钥才能打开，否则是空目录| P0 |

## 7. SFTP 插件

| ID | 场景 | 步骤 | 预期 | 优先级 |
|---|---|---|---|---|
| S1 | 密码连接 | 地址栏 sftp://u@host，弹框输密码 | 连接成功，目录列出 | P0 |
| S2 | 密钥连接 | 密钥登录，keyPath 留空 | 自动找 ~/.ssh/id_*，连接成功 | P0 |
| S3 | 路径栏 sftp:// | 地址栏输 sftp:// 回车 | 弹空白连接框 | P1 |
| S4 | 路径栏 sftp://u@host | 地址栏输 sftp://u@host 回车 | 弹预填连接框 | P1 |
| S5 | 主密码设置 | 首次连接勾选保存密码 | 提示设主密码 | P1 |
| S6 | 主密码验证 | 已保存密码的服务器重连 | 要求输主密码 | P0 |
| S7 | 忘记主密码 | MasterKeyDialog→忘记主密钥 | 确认后重置，所有保存密码清除 | P1 |
| S8 | 会话恢复 | 退出保存→重开 | SFTP 布局恢复，要求主密码后自动连接 | P0 |
| S9 | 未验证主密码 | 会话恢复时取消主密码 | 保留布局，不连接，不刷新 | P1 |
| S10 | 已连接后刷新 | SFTP 已连接，点左侧服务器 | 目录正确加载（不是本地内容） | P0 |
| S11 | SFTP 删除 | SFTP 右键删除文件夹 | 删除成功 | P1 |
| S12 | SFTP 分组 | 添加服务器到分组 | 左侧按分组显示 | P2 |
| S13 | SFTP 上传文件夹并发 | 本地文件夹ctrl+c复制，sftp窗口粘贴 | 并发批量上传到sftp服务器，且统计文件总数构建总进度条 | P0 |
| S14 | SFTP 下载文件夹并发 | sftp文件夹ctrl+c复制，本地窗口路径粘贴 | 并发批量下载到本地，且统计文件总数构建总进度条| P0 |
| S15 | SFTP 上传文件并发 | 本地多个文件ctrl+c复制，sftp窗口粘贴 | 并发批量上传到sftp服务器，且统计文件总数构建总进度条 | P0 |
| S16 | SFTP 下载文件并发 | sftp多个文件ctrl+c复制，本地窗口路径粘贴 | 并发批量下载到本地，且统计文件总数构建总进度条| P0 |
| S17 | SFTP 传输并发设置 | 进入配置窗口，点击sftp设置 | 可以指定是串行下载还是并发下载，并发下载每次并发数量，默认为5| P0 |
| S18 | SFTP 传输断点续传 | sftp上传| 开始上传，支持断点续传| P0 |
| S19 | SFTP 传输断点续传 | sftp下载| 开始下载，支持断点续传| P0 |
| S20 | SFTP 拖动传输 | 本地拖到sftp窗口，然后sftp窗口拖到本地| 正常传输| P0 |

## E2E 实施范围（Playwright）

首批自动化（Windows + WSL）：
- W1, W3, W4（启动/加载/字体）
- T1, T2（标签新建/关闭）
- N1, N2, N3, N7（前进后退/F5）
- L1（虚拟滚动完整）
- L3（矩形框选）
- S1, S10（SFTP 连接+目录加载）
- F6（本地→SFTP 上传）
- H1, H3, H5（HTTP autoindex）

人工回归（macOS + 视觉）：
- W2 开屏动画、W6/W7 菜单 hover
- 所有右键菜单视觉
- 分享浏览器端交互
- 压缩进度条视觉
